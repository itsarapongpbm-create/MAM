สร้างเอกสารใหม่ด่วน

ใบเสนอราคา (Quotation) เสนอราคาสินค้าหรือบริการให้ลูกค้า
ใบวางบิล / แจ้งหนี้ (Billing) แจ้งยอดเรียกเก็บเงินเมื่อส่งมอบงาน
ใบเสร็จรับเงิน (Receipt) ออกเอกสารเมื่อได้รับเงินชำระครบแล้ว
ใบกำกับภาษี / ส่งของ (Tax Invoice) ส่งมอบสินค้าและออกใบกำกับภาษี
บันทึกค่าใช้จ่าย (Expense) บันทึกบิลค่าใช้จ่ายและแนบรูปสลิป
หัก ณ ที่จ่าย (50 ทวิ) หนังสือรับรองตามแบบสรรพากร
ใบสั่งซื้อ (Purchase Order) สั่งซื้อสินค้าหรือบริการจากคู่ค้า
บิลขายเงินสด (Cash Sale) ขายสินค้าและรับชำระเงินสดทันที
เพิ่มลูกค้า / คู่ค้าใหม่ สร้างประวัติและเลขประจำตัวผู้เสียภาษี

+ เพิ่มลูกค้า / คู่ค้าใหม่

+ เพิ่ม / อัปเดตบัญชีการเงิน
